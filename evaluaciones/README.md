# Evaluaciones

Los datasets de esta carpeta son provisionales y deben revalidarse cuando llegue el contador, tal como marca el Gantt del proyecto.

- `evaluaciones/data/eval_dataset.json`: base provisional para las métricas de Recall@k.
- `evaluaciones/data/eval_ruteo.json`: base provisional para la precisión del enrutador.

Usar estos archivos como referencia de CI no implica que estén cerrados; cualquier cambio en el corpus o en las reglas de negocio requiere volver a medirlos antes de abrir el PR final.
